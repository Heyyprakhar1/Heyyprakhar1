# 🚀 Featured DevOps & Cloud Projects

## 🔐 DevSecOps CI/CD Pipeline — Two-Tier Flask App ⭐ NEW

🔗 [github.com/Heyyprakhar1/two-tier-app](https://github.com/Heyyprakhar1/two-tier-app)

A complete **end-to-end DevSecOps pipeline** built with GitHub Actions for a two-tier Flask + MySQL application.
80 failed runs. 8 production bugs fixed. One green signal in 2m 43s.

**Pipeline Architecture:**
```
Code Push
  → [Parallel] Code Quality · Secrets Scan · Dependency Check · Dockerfile Scan
  → Docker Build & Push (ECR/Docker Hub)
  → Trivy Image Scan
  → SSH/SCP Auto-Deploy to Production Server
```

**What's inside — 7 Reusable Workflows:**

| Workflow | Tool | Purpose |
|---|---|---|
| code-quality-scan | Bandit | Python SAST |
| secrets-scan | Gitleaks | Secret detection |
| dependency-check | pip-audit | Vulnerable packages |
| dockerfile-scan | Hadolint | Dockerfile best practices |
| docker-build-push | Docker | Build & tag with SHA |
| image-scan | Trivy | Container vulnerability scan |
| deploy-to-prod | SSH + SCP | Auto-deploy via appleboy |

✔ Reusable workflows with `workflow_call` · ✔ `secrets: inherit` · ✔ SHA-tagged images · ✔ `sudo -E docker compose` · ✔ `service_healthy` condition · ✔ Gunicorn production server
